08 · 三维透视投影 —— 近大远小

理解透视除法、FOV、宽高比、近远裁面。

一、透视的本质：除以 w

透视投影矩阵会把顶点的 z 信息写进裁剪坐标的 w 分量。GPU 在裁剪后会自动执行透视除法：(x, y, z) ← (x/w, y/w, z/w)。离相机越远（w 越大），坐标被缩得越小——这就是「近大远小」。

perspective(fovY, aspect, near, far) = 
[ f/aspect, 0,  0,            0,
  0,        f,  0,            0,
  0,        0,  far·nf,      -1,   // 注意这里的 -1
  0,        0,  near·far·nf,  0 ]
其中 f = 1/tan(fovY/2),  nf = 1/(near-far)

⚠️第 3 列第 4 行的 -1 会把 -z 放进 w，于是 w = -z。又因为相机看向 -z 方向，物体的 z 是负值，w 就变成正的距离。深度项 far·nf / near·far·nf 按 WebGPU 的 [0,1] 深度范围设计（与 WebGL [-1,1] 不同）。

二、三个关键参数

参数含义调大效果
FOV（视野角）垂直方向能看到的角度视野变广、透视更夸张（鱼眼感）
aspect（宽高比）canvas 宽 / 高防止画面横向或纵向拉伸
near / far近/远裁剪面距离可见深度范围；比值过大会有 Z-fighting

📷小 FOV ≈ 长焦镜头（压缩空间），大 FOV ≈ 广角镜头（夸张近大远小）。游戏里常用 45°~75°。

三、把物体推到相机前方

相机默认在原点看向 -z。F 也在原点，会「贴脸」甚至被近裁面切掉。所以要先把它沿 -z 平移一段距离：

let m = mat4.multiply(proj, mat4.translation(0, 0, -dist));
m = mat4.multiply(m, mat4.rotationY(ry));

拖动「距离」滑块，会看到 F 随距离变小/变大——这是正射投影做不到的效果。

四、Z-fighting 与 near/far

⚠️深度缓冲精度有限，且透视投影下深度非线性（绝大部分精度集中在近处）。如果 near 设得过小（如 0.001）、far 过大（如 100000），远处物体的深度会因精度不足而「闪烁打架」（Z-fighting）。经验法则：near 尽量大、far 尽量小，够用即可。本例用 near=1, far=2000。

五、与正射投影的对比

  • 正射：平行投影，无 w 除法，远近等大；矩阵第 4 行是 (0,0,0,1)。
  • 透视：有 w 除法，远近不等大；矩阵第 4 行含 -1。

六、动手练习

  1. 同时改变 FOV 和距离，让 F 屏幕大小不变但透视感变化（电影里的「滑动变焦/眩晕镜头」）。
  2. 把 near 改成 300，观察 F 前半部分被近裁面切掉。
  3. 加一个绕 X 轴旋转，从上往下俯视 F。
