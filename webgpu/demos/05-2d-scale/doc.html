05 · 二维缩放 —— 乘法与镜像

理解缩放变换，以及负缩放因子带来的镜像翻转。

一、缩放公式

缩放就是把坐标乘以缩放因子：

$$x' = x \cdot s_x \qquad y' = y \cdot s_y$$

在 WGSL 里利用向量逐分量乘法一行搞定：

let scaled = pos * u.scale;  // vec2f * vec2f 逐分量相乘

二、负缩放 = 镜像

🪞当 scaleX = -1 时，所有点的 x 坐标取反，图形沿 Y 轴左右翻转；scaleY = -1 则沿 X 轴上下翻转。两者同时为 -1 等价于旋转 180°。

试试在 Demo 里把缩放 X 拖到 -1，会看到 F 变成镜像的 "ꟻ"。

三、变换顺序：先缩放后平移

本例着色器顺序是 缩放 → 平移：

let scaled = pos * u.scale;
let moved = scaled + u.translation;

如果反过来「先平移后缩放」，平移量本身也会被放大，物体会跑到意想不到的位置。缩放和旋转一样，都是绕原点进行的，所以通常先做缩放/旋转、再做平移。

⚠️这正是接下来第 06 节要解决的核心问题：当变换越来越多，手动控制顺序很麻烦，矩阵能把任意顺序的变换优雅地组合起来。

四、缩放对几何中心的影响

和旋转一样，缩放也以原点为中心。F 的原点在左上角，所以放大时它会向右下「长大」，而不是从中心均匀膨胀。要从中心缩放，需先把几何平移到原点对齐中心。

五、动手练习

  1. 把缩放范围扩大到 -3~3，观察大幅镜像与拉伸。
  2. 让 F 从自身中心缩放（先减 (50,75) 再缩放再加回）。
  3. 把缩放、旋转、平移三个变换全部加进同一个着色器，体会手动管理顺序的复杂度——然后进入第 06 节用矩阵简化它。
