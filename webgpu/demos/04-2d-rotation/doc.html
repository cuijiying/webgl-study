04 · 二维旋转 —— sin / cos 的魔法

从几何角度推导二维旋转公式，并在 WGSL 中实现。

一、旋转公式从哪来？

把点 (x, y) 绕原点逆时针旋转角度 θ，新坐标为：

$$x' = x\cos\theta - y\sin\theta$$ $$y' = x\sin\theta + y\cos\theta$$

推导思路：用极坐标表示点 (x,y) = (r·cosφ, r·sinφ)，旋转后角度变为 φ+θ，再用和角公式展开 cos(φ+θ)、sin(φ+θ) 即得上式。

📐本质上这就是二维旋转矩阵：

$$\begin{bmatrix}x'\\y'\end{bmatrix}=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}$$

第 06 节会把它升级为矩阵形式。

二、为什么把 sin/cos 在 JS 里算好？

三角函数对所有顶点都一样，是典型的 uniform。我们在 JS 里算一次 Math.sin/cos，作为 vec2f rotation = (sin, cos) 传入，避免 GPU 上每个顶点重复计算，也方便理解。

const rad = angle * Math.PI / 180;
uniformData[4] = Math.sin(rad);  // rotation.x
uniformData[5] = Math.cos(rad);  // rotation.y

三、WGSL 实现

let rotated = vec2f(
  pos.x * u.rotation.y - pos.y * u.rotation.x,  // x·cos − y·sin
  pos.x * u.rotation.x + pos.y * u.rotation.y,  // x·sin + y·cos
);
let moved = rotated + u.translation;

注意顺序：先旋转，后平移。因为旋转是绕原点进行的，如果先平移会让旋转中心也跟着移动，效果完全不同（下一节缩放、第 06 节矩阵会反复强调这点）。

⚠️本例 F 绕它的局部原点（左上角）旋转，所以看起来像「甩」出去。若想绕几何中心旋转，需先把顶点平移 -(宽/2, 高/2)，旋转后再平移回来。

四、Uniform 内存布局

字段类型字节偏移
resolutionvec2f0
translationvec2f8
rotationvec2f16

三个 vec2f 共 24 字节。由于 uniform buffer 推荐按 16 字节对齐，我们直接分配 32 字节（Float32Array(8)），多出的部分不使用即可。

五、动手练习

  1. 让 F 绕自身中心旋转（提示：几何顶点先减去 (50, 75)）。
  2. 把角度做成自动旋转动画（用 requestAnimationFrame，参考第 14 节）。
  3. 直接在 WGSL 里接收角度 f32，用内置 sin()/cos() 计算，对比两种写法。
