07 · 三维正射投影 —— 进入 3D 与深度测试

绘制有厚度的 3D F，掌握 mat4x4、深度纹理，以及 WebGPU 的 [0,1] 深度范围。

一、从 2D 到 3D 改了什么？

  • 顶点从 vec2f 变 vec3f（多了 z）。
  • 矩阵从 3×3 升级为 mat4x4f（64 字节连续，无对齐烦恼）。
  • 新增深度纹理 (Depth Texture) 与深度测试，解决「谁遮挡谁」。
  • 几何来自 geometry.js，每个顶点含位置、颜色、法线（法线本节先不用）。

二、正射投影 vs 透视投影

正射投影 (Orthographic) 不考虑距离，远近物体一样大，常用于工程制图、2D 游戏、UI。它把一个长方体空间线性映射到裁剪空间：

proj = mat4.orthographic(left, right, bottom, top, near, far);

⚠️WebGPU 的深度范围是 [0, 1]，而 WebGL 是 [-1, 1]。这意味着投影矩阵的第三行/列算法不同！如果直接套用 WebGL 教程的矩阵公式，深度会出错。本教程的 WebGPUUtils.mat4 已按 WebGPU 规范实现，放心使用。

三、深度测试三件套

1) 创建深度纹理

const depthTexture = device.createTexture({
  size: [canvas.width, canvas.height],
  format: 'depth24plus',
  usage: GPUTextureUsage.RENDER_ATTACHMENT,
});

深度纹理与画布同尺寸，每个像素存一个深度值（0=最近，1=最远）。

2) 管线声明 depthStencil

depthStencil: {
  format: 'depth24plus',
  depthWriteEnabled: true,   // 通过测试就写入新深度
  depthCompare: 'less',        // 新深度 < 旧深度 才通过（更近者胜）
}

3) 渲染通道挂上深度附件

depthStencilAttachment: {
  view: depthTexture.createView(),
  depthClearValue: 1.0,      // 每帧先把深度清成最远
  depthLoadOp: 'clear',
  depthStoreOp: 'store',
}

🧠深度测试原理：光栅化每个像素时，GPU 拿它的 z 和深度纹理里已有的值比较。depthCompare:'less' 表示只有更近（z 更小）的片元才被画上去并更新深度。这样无论三角形提交顺序如何，最终都正确遮挡。这就是著名的 Z-Buffer 算法。

四、关于背面剔除（Culling）

本例 cullMode:'none'，所有面都画。生产中常用 cullMode:'back' 剔除背对相机的面以省一半绘制量，但需保证三角形缠绕方向 (winding) 一致。WebGPU 默认 frontFace:'ccw'（逆时针为正面）。若开启剔除后物体「破面」，多半是缠绕方向不符，把 cullMode 改 'front' 或调整顶点顺序即可。

五、矩阵组合

let m = mat4.multiply(proj, mat4.rotationX(rx));
m = mat4.multiply(m, mat4.rotationY(ry));

顺序仍是「最右最先」：顶点先绕 Y、再绕 X、最后投影。几何已在 geometry.js 里居中（减去 50,75,15），所以旋转绕物体中心进行。

六、动手练习

  1. 把 depthCompare 改成 'always'，观察深度测试失效后 F「穿帮」的样子。
  2. 开启 cullMode:'back'，若破面就改成 'front'，理解缠绕方向。
  3. 把正射换成「歪斜」的投影体，观察图形被拉伸。
