03 · 二维平移 —— Uniform 与 Bind Group 入门

第一次使用 Uniform Buffer 把全局参数传给着色器，并理解 WebGPU 的「绑定组」机制。

一、什么是 Uniform？

顶点属性 (attribute) 是逐顶点不同的数据；而 Uniform 是对一次绘制中所有顶点都相同的全局常量，比如平移量、变换矩阵、颜色、时间等。在 WebGPU 里，uniform 数据存放在一个 Uniform Buffer 中，通过 Bind Group 绑定到管线。

二、像素坐标 → 裁剪空间

前两节顶点直接写裁剪空间坐标（-1~1），不直观。本节改用像素坐标定义几何（一个 "F"，宽 100、高 150），再在着色器里换算：

let moved = pos + u.translation;          // ① 平移（像素）
let zeroToOne = moved / u.resolution;      // ② 归一化到 0~1
let clip = zeroToOne * 2.0 - 1.0;        // ③ 映射到 -1~1
return vec4f(clip.x, -clip.y, 0.0, 1.0);  // ④ 翻转 Y

🔄为什么翻转 Y？屏幕/图片的 Y 轴向下增大（原点左上），而裁剪空间 Y 轴向上增大（原点中心）。所以最后给 clip.y 取负，让 F 正立显示。

三、WGSL 中声明 Uniform

struct Uniforms {
  resolution : vec2f,
  translation : vec2f,
};
@group(0) @binding(0) var<uniform> u : Uniforms;
  • @group(0)：属于第 0 号绑定组。
  • @binding(0)：在该组内的第 0 号绑定点。
  • var<uniform>：地址空间为 uniform（只读）。

四、JS 端：创建 Buffer 与 Bind Group

// uniform 缓冲：4 个 f32 = 16 字节
const uniformBuffer = device.createBuffer({
  size: 16,
  usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST,
});

const bindGroup = device.createBindGroup({
  layout: pipeline.getBindGroupLayout(0),  // 取 group(0) 的布局
  entries: [{ binding: 0, resource: { buffer: uniformBuffer } }],
});

📦Bind Group 是什么？可以把它理解成「一捆资源的打包」——把若干 buffer / texture / sampler 按 binding 号绑在一起，绘制前用 setBindGroup(0, bindGroup) 一次性挂上去。这比 WebGL 一个个 uniformXX 设置高效得多。

五、每帧更新与绘制

uniformData.set([canvas.width, canvas.height, tx, ty]);
device.queue.writeBuffer(uniformBuffer, 0, uniformData);
// ...
pass.setBindGroup(0, bindGroup);
pass.draw(F.length / 2);

滑块改变后只需重写 uniform 缓冲并重绘，几何缓冲区无需改动。

六、内存对齐速查（重要）

WGSL 的 uniform 结构有严格的对齐规则，常成为新手的坑：

类型对齐(字节)大小(字节)
f32 / i32 / u3244
vec2f88
vec3f1612 ⚠️
vec4f1616
mat4x4f1664

⚠️vec3f 对齐是 16 但只占 12 字节，紧跟其后的字段会被「顶到」下一个 16 字节边界，极易算错偏移。本例两个 vec2f 各 8 字节正好凑成 16，无对齐陷阱。涉及 vec3 时建议改用 vec4 或重排字段。

七、动手练习

  1. 再加一个 uniform color: vec4f，用滑块控制 F 的颜色（注意把结构补齐到 16 字节对齐）。
  2. 用鼠标拖动代替滑块（监听 pointermove，把鼠标坐标作为平移量）。
