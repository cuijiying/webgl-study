12 · 纹理贴图 —— 把图片贴到表面

掌握 GPUTexture、GPUSampler、UV 坐标与多资源 Bind Group。

一、纹理是什么？

纹理 (Texture) 就是一张存在 GPU 上的图片。我们用 UV 坐标（也叫纹理坐标）告诉每个顶点「采样图片的哪个位置」。UV 范围是 0~1：(0,0) 是图片一角，(1,1) 是对角。

二、纹理三件套

WebGPU 里用一张纹理需要三个对象，分别绑定到 bind group 的不同 binding：

对象WGSL 类型作用
GPUTexture（的 view）texture_2d<f32>存储像素数据
GPUSamplersampler决定如何读取（过滤、寻址）
Uniform Buffervar<uniform>矩阵等参数
@group(0) @binding(0) var<uniform> u : Uniforms;
@group(0) @binding(1) var samp : sampler;
@group(0) @binding(2) var tex : texture_2d<f32>;

三、创建纹理并上传图片

const texture = device.createTexture({
  size: [w, h],
  format: 'rgba8unorm',
  usage: GPUTextureUsage.TEXTURE_BINDING   // 着色器可采样
       | GPUTextureUsage.COPY_DST          // 可被写入
       | GPUTextureUsage.RENDER_ATTACHMENT,
});
device.queue.copyExternalImageToTexture(
  { source: srcCanvas, flipY: true },  // 来源：img / canvas / ImageBitmap
  { texture },
  [w, h]
);

🖼️本例没有加载外部图片，而是用 2D Canvas 程序生成了一张带渐变、棋盘格和文字的图，再作为 source 上传。实际项目中通常用 const img = await createImageBitmap(await (await fetch(url)).blob()) 加载图片文件。

🔄flipY:true：图片坐标 Y 向下，而我们的 UV (0,0) 在左下，需翻转 Y 让图片正立。

四、采样器：linear vs nearest

const sampler = device.createSampler({
  magFilter: 'linear',   // 放大时的过滤
  minFilter: 'linear',   // 缩小时的过滤
});
过滤效果适用
linear相邻像素插值，平滑照片、真实贴图
nearest取最近像素，硬边/马赛克像素艺术、色块图

Demo 里切换下拉框，放大立方体表面就能看到两者区别。还有一个 addressMode 控制 UV 超出 0~1 时的行为（repeat 平铺 / clamp-to-edge 拉伸边缘 / mirror-repeat 镜像）。

五、在着色器里采样

@fragment
fn fs(in : VSOut) -> @location(0) vec4f {
  return textureSample(tex, samp, in.uv);
}

textureSample(纹理, 采样器, UV) 返回该 UV 处的颜色。UV 由顶点着色器输出、经光栅化插值后传入。

六、Bind Group 打包多种资源

device.createBindGroup({
  layout: pipeline.getBindGroupLayout(0),
  entries: [
    { binding: 0, resource: { buffer: uniformBuffer } },
    { binding: 1, resource: sampler },
    { binding: 2, resource: texture.createView() },
  ],
});

一个 bind group 可以同时绑定 buffer、sampler、texture，binding 号与 WGSL 里一一对应。

七、动手练习

  1. 把 UV 乘以 2（in.uv * 2.0）配合 addressMode:'repeat'，让纹理在每个面平铺 2×2。
  2. 加载一张真实图片文件替换程序纹理。
  3. 结合第 11 节，给纹理立方体加上点光源光照（纹理色 × 光照亮度）。
  4. 开启 mipmap（generateMipmap）减少远处纹理的闪烁。
