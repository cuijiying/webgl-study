09 · 三维相机 —— lookAt 与视图矩阵

理解相机矩阵、视图矩阵，以及「投影 × 视图 × 模型」的完整变换链。

一、相机其实是个错觉

GPU 里并没有「相机」这种东西，相机永远固定在原点看向 -z。所谓移动相机，本质是把整个世界做反向变换。如果相机向右移动 5，等价于把世界向左移动 5。

🎥视图矩阵 = 相机世界变换矩阵的逆。先求出相机在世界中的位置与朝向（相机矩阵），再取逆，就得到把世界变换到「相机视角」的视图矩阵。

二、lookAt 矩阵怎么构造？

lookAt(eye, target, up) 让相机位于 eye、朝向 target。它先算出相机的三个正交基轴：

zAxis = normalize(eye - target)   // 相机朝向的反方向（看向 -z）
xAxis = normalize(cross(up, zAxis)) // 右
yAxis = cross(zAxis, xAxis)        // 上

本教程的 WebGPUUtils.mat4.lookAt 直接返回视图矩阵（已经做好求逆），所以可以直接用：

const view = mat4.lookAt(eye, [0,0,0], [0,1,0]);

三、完整变换链

$$\text{裁剪坐标} = P \cdot V \cdot M \cdot \text{顶点}$$

矩阵作用
M（模型矩阵）把物体从局部空间摆到世界中的位置
V（视图矩阵）把世界变换到相机视角
P（投影矩阵）把相机空间投影到裁剪空间
const viewProj = mat4.multiply(proj, view);
// 每个物体：
const m = mat4.multiply(viewProj, model);

💡把 P·V 预先算好（viewProj），再对每个物体乘各自的 model，可以省下大量重复计算。这是引擎里常见的优化。

四、本例：相机绕一圈 F 旋转

我们摆了 5 个 F 围成圆环，相机绕世界原点环绕，始终看向圆心：

const a = angle * Math.PI / 180;
const eye = [Math.sin(a) * radius, height, Math.cos(a) * radius];
const view = mat4.lookAt(eye, [0,0,0], [0,1,0]);

注意：移动的是相机，F 们本身一动不动。这正体现了相机与物体运动的等价性。

五、绘制多个物体的简单做法

本例给每个 F 准备了独立的 uniform buffer 和 bind group，循环里逐个 writeBuffer + setBindGroup + draw：

for (let i = 0; i < NUM_F; i++) {
  const m = mat4.multiply(viewProj, model[i]);
  device.queue.writeBuffer(uniformBuffers[i], 0, m);
  pass.setBindGroup(0, bindGroups[i]);
  pass.draw(96);
}

物体很多时这样会创建大量 buffer，第 13 节会介绍更高效的动态偏移 (dynamic offset) 方案。

六、动手练习

  1. 把相机 target 改成第一个 F 的位置，让相机「锁定」某个 F。
  2. 用 requestAnimationFrame 让相机自动环绕（参考第 14 节）。
  3. 把 up 向量改成 (0,0,1)，观察相机「翻滚」的怪异效果，理解 up 的作用。
