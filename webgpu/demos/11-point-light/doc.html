11 · 点光源与高光 —— Blinn-Phong 模型

从方向光升级到有位置的点光源，并加入镜面高光。

一、点光源 vs 方向光

方向光点光源
是否有位置否（无限远）有具体世界坐标
光线方向处处相同逐表面点不同
计算关键固定 lightDirlightPos − 表面世界坐标

所以点光源需要知道每个片元的世界坐标，才能算出该点指向光源的方向。这就要把模型矩阵也传进着色器，在顶点着色器里算世界坐标。

二、三个关键方向向量

let worldPos = (u.model * vec4f(pos, 1.0)).xyz;
o.surfaceToLight = u.lightPos - worldPos;  // L：表面 → 光源
o.surfaceToView  = u.viewPos  - worldPos;  // V：表面 → 相机
o.normal = (u.normalMatrix * vec4f(normal, 0.0)).xyz;

📍这些向量在顶点着色器算出后，会被光栅化插值到每个片元。片元着色器里再 normalize，因为插值会改变长度。

三、漫反射 + 镜面高光

漫反射（同上一节）

let diffuse = max(dot(n, L), 0.0);

镜面高光（Blinn-Phong）

当视线方向正好处在光线的「镜面反射」路径上时，会看到刺眼的高光。Blinn 的巧妙简化是引入半程向量 H（L 和 V 的平均方向）：

$$\vec{H} = \text{normalize}(\vec{L}+\vec{V}) \qquad specular = (\max(\vec{n}\cdot\vec{H},0))^{shininess}$$

let H = normalize(L + V);
var specular = 0.0;
if (diffuse > 0.0) {
  specular = pow(max(dot(n, H), 0.0), u.shininess);
}

✨shininess（光泽度）控制高光大小：值越大，高光越小越锐利（像抛光金属/塑料）；值越小，高光越大越柔和（像粗糙表面）。拖动滑块从 1 到 300 感受材质变化。

四、最终颜色合成

let rgb = in.color * (ambient + diffuse * 0.85) + vec3f(specular);
  • 环境光 ambient：基础亮度，避免全黑。
  • 漫反射 diffuse：物体本色，受光照角度影响。
  • 镜面高光 specular：通常是白色叠加（与物体颜色无关），所以直接 + vec3f(specular)。

五、相机世界坐标怎么来？

本例相机固定在 (0, 0, DIST) 看向原点（视图矩阵是 translation(0,0,-DIST)）。所以 viewPos = (0, 0, DIST)。如果用了 lookAt，相机世界坐标就是 lookAt 里的 eye。

七、动手练习

  1. 给点光源加距离衰减：亮度乘以 1/(distance²)，模拟真实光强随距离减弱。
  2. 把高光颜色改成光源颜色而非纯白。
  3. 让光源绕物体公转，观察高光点在表面移动。
