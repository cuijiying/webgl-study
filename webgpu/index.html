🚀 WebGPU 学习练习集

下一代 Web 图形与计算 API。与 WebGL 教程 一一对应，从第一个三角形到计算着色器。每个 Demo 都配有详细说明文档 + 可交互演示。

ℹ️运行要求：WebGPU 需要 Chrome 113+ / Edge 113+ / Safari 17.4+，且开启硬件加速。每个 Demo 页右上角都有「📖 查看详细文档」按钮。

一、基础概念

01

Hello Triangle - 第一个三角形

WebGPU 完整启动流程：适配器/设备、配置 canvas、WGSL 着色器、渲染管线、命令编码器与渲染通道。

 02

工作原理 - 顶点缓冲与插值

使用顶点缓冲区传入位置+颜色，理解 inter-stage 变量插值、@location 绑定，以及顶点/片元阶段的数据流。

二、Uniform 与二维变换

03

二维平移 (Uniform 入门)

第一次使用 Uniform Buffer 与 Bind Group。通过滑块把平移量传入着色器。

 04

二维旋转

在 WGSL 中用 sin/cos 实现旋转，理解三角函数与旋转矩阵的关系。

 05

二维缩放

X/Y 独立缩放与镜像翻转，理解缩放对几何的影响。

 06

二维矩阵变换

将平移/旋转/缩放统一为 3x3（mat3x3）矩阵，理解 WGSL 矩阵内存对齐。

三、三维空间

07

三维正射投影

3D 的 "F" 字母，深度测试（depth texture），WebGPU 的 [0,1] 深度范围与背面剔除。

 08

三维透视投影

近大远小的透视矩阵，FOV / 宽高比 / 近远裁面。

 09

三维相机

lookAt 矩阵与视图矩阵，让相机围绕目标旋转观察。

四、光照

10

方向光源

法线、点积、法线矩阵，实现方向光（类太阳光）漫反射。

 11

点光源 + 高光

点光源方向计算与 Blinn-Phong 高光反射。

五、纹理

12

纹理贴图

GPUTexture、GPUSampler、copyExternalImageToTexture，UV 坐标与采样。

六、组织与进阶

13

绘制多个物体

动态 Uniform Offset / 多个 Bind Group，在一个渲染通道中绘制多个物体。

 14

动画

requestAnimationFrame + 每帧更新 Uniform，deltaTime 时间管理。

 15

计算着色器 (Compute)

WebGPU 杀手级特性！用 compute shader 做图像处理（卷积核），workgroup 与 storage buffer。
