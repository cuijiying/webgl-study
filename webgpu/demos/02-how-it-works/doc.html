02 · 工作原理 —— 顶点缓冲与插值

理解顶点缓冲区内存布局、inter-stage 变量，以及光栅化阶段的重心插值。

一、本节目标

  • 用 createBuffer + writeBuffer 把顶点数据上传到 GPU
  • 用 vertex.buffers 描述「一个顶点在内存里长什么样」
  • 理解 @location 在顶点输入、inter-stage、片元输出三处的不同含义
  • 看懂 GPU 如何对三角形内部做颜色插值

二、渲染管线全貌

顶点缓冲(GPU内存)
   │  按 arrayStride 切片，每片是一个顶点
   ▼
顶点着色器 vs()   逐顶点执行（本例 3 次）
   │  输出 @builtin(position) + @location(0) color
   ▼
图元装配 + 光栅化   把三角形铺成像素，并对 location 变量插值 ★
   │
   ▼
片元着色器 fs()   逐像素执行（成千上万次）
   │  输出 @location(0) 颜色
   ▼
画布纹理

★插值发生在光栅化阶段：顶点着色器只跑 3 次，但三角形内部有成千上万个像素。每个像素的 color 是由三个顶点颜色按「重心坐标」加权得到的——离哪个顶点近，就更接近那个顶点的颜色。这就是渐变的来源。

三、顶点数据与内存布局

我们把位置和颜色交错（interleaved）存在同一个数组里：

const vertexData = new Float32Array([
// x     y      r    g    b    a
   0.0,  0.5,   1.0, 0.2, 0.3, 1.0,  // 顶点0
  -0.5, -0.5,   0.2, 1.0, 0.4, 1.0,  // 顶点1
   0.5, -0.5,   0.3, 0.5, 1.0, 1.0,  // 顶点2
]);

创建缓冲区时必须声明用途 (usage)，WebGPU 据此分配最优内存：

const vertexBuffer = device.createBuffer({
  size: vertexData.byteLength,
  usage: GPUBufferUsage.VERTEX | GPUBufferUsage.COPY_DST,
});
device.queue.writeBuffer(vertexBuffer, 0, vertexData);
  • GPUBufferUsage.VERTEX：作为顶点缓冲使用。
  • GPUBufferUsage.COPY_DST：允许被 writeBuffer 写入（作为拷贝目标）。
  • writeBuffer(buffer, offset, data) 是上传数据最简单的方式。

四、用 buffers 描述布局

buffers: [{
  arrayStride: 6 * 4,  // 步长：每个顶点 6 个 f32 = 24 字节
  attributes: [
    { shaderLocation: 0, offset: 0,   format: 'float32x2' }, // pos
    { shaderLocation: 1, offset: 8,   format: 'float32x4' }, // color
  ],
}]
字段含义
arrayStride从一个顶点到下一个顶点跨多少字节
shaderLocation对应 WGSL 里的 @location(n)
offset该属性在单个顶点内的字节偏移（颜色前面有 2 个 f32，故 = 8）
format数据格式，float32x2=vec2f，float32x4=vec4f

💡这套描述等价于 WebGL 的 vertexAttribPointer，但 WebGPU 把它放进管线里一次定义好，运行时无需反复设置，更高效也更不易出错。

五、WGSL 中的 @location 三种身份

struct VSOut {
  @builtin(position) position : vec4f,  // 裁剪坐标（特殊）
  @location(0) color : vec4f,           // inter-stage 变量
};

@vertex
fn vs(@location(0) pos: vec2f,        // ← 顶点输入属性
       @location(1) color: vec4f) -> VSOut { ... }

@fragment
fn fs(in: VSOut) -> @location(0) vec4f { // ← 颜色附件输出
  return in.color;
}

⚠️三处 @location 的编号空间是独立的：

  • 顶点函数参数上的 location ↔ JS 里的 shaderLocation
  • VSOut 里的 location ↔ 顶点输出与片元输入之间的匹配（按编号配对）
  • 片元返回值上的 location ↔ colorAttachments 的索引

六、绑定并绘制

pass.setPipeline(pipeline);
pass.setVertexBuffer(0, vertexBuffer); // slot 0 对应 buffers[0]
pass.draw(3);

七、动手练习

  1. 把三个顶点颜色都改成同一种，观察渐变消失。
  2. 在 inter-stage 变量上加 @interpolate(flat)，看看「平坦着色」效果（取最后一个顶点的颜色，不插值）。
  3. 把颜色单独放到第二个顶点缓冲区（slot 1），改用非交错布局。
