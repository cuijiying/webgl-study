10 · 方向光源 —— 法线与点积

实现最基础的漫反射光照，理解法线、法线矩阵与点积的几何意义。

一、什么是方向光？

方向光（Directional Light）模拟无限远的光源，比如太阳。它的所有光线平行，只有方向、没有位置。一个表面有多亮，取决于它正对光源的程度。

二、点积 = 朝向程度

两个单位向量的点积等于它们夹角的余弦：

$$\vec{n}\cdot\vec{l} = \cos\theta$$

  • 法线与光照方向平行同向（正对光）→ 点积 = 1 → 最亮
  • 垂直（侧面对光）→ 点积 = 0 → 不亮
  • 背对光 → 点积为负 → 用 max(..., 0) 截断为 0（不会负亮度）
let light = max(dot(n, normalize(u.lightDir)), 0.0);
let brightness = 0.2 + light * 0.8; // 0.2 是环境光

🌑环境光 (ambient)：纯漫反射会让背光面全黑，不真实。加一个小常量（这里 0.2）模拟环境中四处反射的微光，让暗面仍可见。

三、法线从哪来？

法线是垂直于表面的单位向量。geometry.js 里为 F 的每个面预设了法线（正面 (0,0,1)、顶面 (0,1,0) 等），作为第三个顶点属性传入：

attributes: [
  { shaderLocation: 0, offset: 0,  format: 'float32x3' }, // 位置
  { shaderLocation: 1, offset: 12, format: 'float32x3' }, // 颜色
  { shaderLocation: 2, offset: 24, format: 'float32x3' }, // 法线
]

四、法线矩阵：为什么不能直接用模型矩阵？

⚠️当物体旋转时法线也要跟着转。但不能直接用模型矩阵变换法线——如果模型含非均匀缩放，法线会被扭曲、不再垂直于表面。正确做法是使用模型矩阵左上 3×3 的逆转置矩阵（法线矩阵）。

const normalMatrix = mat4.inverseTranspose(model);
// 着色器里：
o.normal = (u.normalMatrix * vec4f(normal, 0.0)).xyz;

注意法线用 vec4f(normal, 0.0)——w=0 表示这是方向而非位置，不受平移影响。纯旋转时法线矩阵恰好等于旋转矩阵本身。

六、逐顶点 vs 逐片元光照

本例在片元着色器里计算光照（Per-Fragment / Phong 着色），法线插值后逐像素算，效果平滑。若把计算放到顶点着色器（Per-Vertex / Gouraud），只在顶点算、然后插值亮度，性能更好但低多边形物体会显得「有棱角」。

七、动手练习

  1. 把环境光改成 0，观察背光面全黑。
  2. 让光照方向随时间旋转，做出「日出日落」效果。
  3. 把光照计算移到顶点着色器，对比 Gouraud 与 Phong 的视觉差异。
